How the ATU tunes

A measured search over 131,072 relay settings that uses nothing but the magnitude of the reflection coefficient. No model of the tuner, no element values and no calibration of the network.

In short
  • The tuner reads |Γ| at one relay setting at a time with a low-power carrier: about 99 ms a reading.
  • It reads the bypass first. Good enough (SWR ≤ 1.3) stays bypassed; a near-total reflection is an antenna fault.
  • Otherwise it walks the valley of each topology on a coarse, logarithmic grid of single-element codes, then refines the lowest point it found with a pattern search in code space.
  • It stops at SWR 1.2, when refining can go no further, or after 120 readings, and stores the best setting it read for this band and antenna. A typical tune takes 35–75 readings, 3–7 s.

1. The tuner

The K9HZ ATU is an L network. Eight series inductors and eight shunt capacitors are switched by relays, each in binary-weighted steps, so a setting is two 8-bit codes: L code 0–255 and C code 0–255. A ninth relay, K17, moves the whole capacitor bank from one end of the inductors to the other, which gives the two topologies. K19 and K20 bypass the network, and K18 picks the output connector.

ElementsNominal valuesSetting
L1–L80.05, 0.1, 0.22, 0.45, 1.0, 2.2, 4.4, 8.8 µHL code bit 0–7

Each element is about 2.2 times the one before, more than double, so the code order is also the order of nominal value: code 8 (0.45 µH) is more than codes 1+2+4 together (0.37 µH). The steps are not even, though, and the board's strays and the coils' self-resonance bend the real values away from nominal, most of all on 10 m. The tuner never uses the values. It ranks codes by what it measures.

That makes 2 × 256 × 256 = 131,072 network settings, plus bypass. Reading them all at 99 ms each would take 3.6 hours.

2. Smith chart refresher

A Smith chart plots the reflection coefficient Γ = (Z − 50)/(Z + 50) on the unit disc. The centre is a perfect 50 Ω match, the rim is total reflection, and the distance from the centre is |Γ|, so a circle around the centre is a circle of constant SWR. The upper half is inductive and the lower half capacitive.

Each element of an L network moves the impedance along one family of circles:

  • a series inductor adds +jX, moving clockwise along a circle of constant resistance;
  • a shunt capacitor adds +jB, moving clockwise along a circle of constant conductance.

To end at the centre, the last element (the one nearest the transmitter) must move along a circle through the centre: the r = 1 circle for a series coil, the g = 1 circle for a shunt capacitor. Working from the antenna side, the first element's job is to land on that circle.

3. What the board can reach

The real board is not two ideal elements. Each coil has self-capacitance and loss, the capacitors have lead inductance, and the tracks between them are short transmission lines. 4. Why it needs a search

The SWR bridge measures forward and reflected power, so the tuner knows |Γ| but not its phase. It cannot tell from one reading which way the match lies, and it has no model to predict one. It can only read settings and compare them.

Figure 4 shows |Γ| over the whole code space of each topology as SWR bands. The axes are logarithmic in code, so each single-element code is evenly spaced. Almost all of the space is useless (SWR above 5), and the good settings lie in a narrow valley, often long and diagonal: as L grows, the C that pairs with it changes too. Changing one element at a time from a point outside the valley usually makes things worse in both directions, so a search along one axis at a time stalls; a brute-force scan is far too slow. The search has to follow the valley.

5. The algorithm

The program is ATU_PROG_TUNE in ATUTuneAlgo.cpp. It is a planner: each time the engine has the carrier off, it asks the planner what to do next, and the planner answers "read this setting", "finish with this setting" or "fail". The planner keeps no list of what it has done. It replays its logic against the record of readings, and wherever it needs a |Γ| that is not in the record yet, it asks for that reading. So a setting is never read twice.

5.1 Bypass

The first reading is with the network out. At SWR ≤ 1.3 the tuner stays bypassed and stores that. Above |Γ| = 0.98 (SWR 99) it stops with ATU_FAIL_ANTENNA: an open or a short, which no setting of the network will fix. Otherwise the search starts.

5.2 Walking the valley

For each topology in turn, LC first, the tuner walks along L on the coarse codes 0, 1, 2, 4, 8, …, 128. At each L it finds the best coarse C:

  • At the first L (code 0) it sweeps C up from 0 until |Γ| has risen twice past its minimum.
  • At later Ls the valley is continuous, so it starts at the previous L's best C and descends: up while that gains, and if going up gained nothing at all, down while that gains.

The best C at each L is the valley floor there. The walk stops when the floor has risen twice (by more than 0.005 in |Γ|) since its lowest point, or when the Ls run out. The lowest floor point is that topology's seed.

5.3 Which valley to refine

  • If the LC seed already reaches the target (SWR 1.5), LC is refined at once, and CL is walked only if that refine ends short of the target.
  • Otherwise CL is walked too, and the lower of the two seeds is refined first. If that ends short of the target, the other is refined as well.
  • Whatever happens, the tuner finishes with the best setting it has read, from either topology.

5.4 Refining: pattern search in code space

From the seed, the refine is a compass search on the two codes, with steps that start at half each code's top set bit (at least 2):

  1. Read the four axis steps (L ± step, C ± step).
  2. If none gains by more than 0.003 in |Γ|, read the four diagonals.
  3. Move to the best candidate that gains, then repeat the same move, doubled, for as long as it keeps gaining (a pattern move: it races along the valley floor).
  4. When neither the axes nor the diagonals gain, halve both steps; when both are 1, the refine is done.

The result is stored for the current band and antenna (ED.ATU_State[band][antenna], with the frequency and the SWR). It goes back on the relays whenever that band and antenna are selected, so asking for a tune always means a retune: the search starts again from bypass and ignores the stored setting.

7. Other loads

The same search on three more loads, each on a board whose coils differ from the reference by about 5 %, as another builder's board would. The tuner knows nothing about the difference.

bypassLC walkCL walkLC refineCL refineresult

80 m, 12.5 Ω is a CL load: the LC walk goes nowhere, the CL walk finds the valley at large C, and the refine settles at SWR 1.43 against a best of 1.41. The long tail of refine readings around L 16, C 80 is the pattern search halving its steps on a flat valley floor; it stops when the steps reach 1, because 1.43 is within the target. 40 m, 25 + j100 Ω matches in LC. 20 m, 25 − j100 Ω is beyond this board: the best of all 131,072 settings is SWR 2.96. The tuner returns ATU_FAIL_NO_MATCH, keeps the best setting it read (3.79), and the home screen says so.

8. Taking one reading

The engine (ATUTune.cpp) runs from the main loop and never blocks. On starting it puts the mode state machine in ATU_TUNE_SPACE: T/R relay in transmit, carrier off. The T/R relay then stays in transmit for the whole tune, so it switches twice per tune, not twice per reading. The ATU relays only ever switch with the carrier off.

A tune starts from SSB or CW receive only, on a band where transmit is allowed, at the tune power (2 W by default, 0.5–10 W in the ATU menu). Any front-panel action except volume stops it, as do TX;, RX; and AX0; over CAT, and a band or antenna change made over CAT. A stopped or failed tune puts back the setting the relays had before it.

10. Limits

  • Local search. The refine only improves on the seed's neighbourhood. If the coarse grid misses a valley entirely, the refine will not find it. Walking both topologies, and refining the second when the first falls short, reduces this.
  • |Γ| only. With no phase, every decision is a comparison of two readings, so bridge noise near a flat valley floor can stop a refine a little early. The 0.002–0.005 gain thresholds keep it from chasing noise.
  • Elements past resonance. On 10 m the largest coils and capacitors are past their self-resonance and read badly. The search does not know, it simply passes over them.
  • The frequency. A setting is stored with the frequency it was tuned on. Moving far within the band does not trigger a retune; the operator presses Tune.
  • Tune power. The search keys a carrier for every reading: about 4–7 s of carrier at the tune power, into whatever the antenna presents.

About the figures

Every trace here is the firmware's own search code, compiled for the host and run in the unit-test harness against the circuit model of the board (test/atu_plant/ATUModel.cpp, fitted to VNA measurements of the RF board), with the coil values perturbed by 5 % and an ideal bridge, so the readings equal the true |Γ|. The model is least trustworthy on 10 m and near series resonances. The bench results in section 9 are from the real radio.
